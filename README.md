# ⏳ Modern Countdown Timer

A modern and professional Countdown Timer built using only HTML, CSS, and JavaScript.

This project features a clean glassmorphism UI, dark mode support, smooth animations, responsive layout, and local storage functionality.

---

# ✨ Features

- Modern Glassmorphism Design
- Fully Responsive Layout
- Dark / Light Mode
- Countdown Timer Functionality
- Event Name Support
- Local Storage Support
- Smooth Animations
- Keyboard Accessibility
- Mobile-First Design
- Current Date Display
- Empty State UI
- Validation Handling
- Professional Footer & Header
- Portfolio Ready UI

---

# 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
